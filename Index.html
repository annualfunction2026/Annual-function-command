Firebase setup:
1. Go to console.firebase.google.com and create a project.
2. Add a Web App () and copy its config object.
3. In Authentication → Sign-in method, enable Anonymous.
4. In Realtime Database, create a database and copy its database URL into the config.
5. For this prototype, set Realtime Database rules to:
{ "rules": { "rooms": { "$room": { ".read": "auth != null", ".write": "auth != null" } } } }
6. Paste the full config above and tap Connect. This simple prototype rule is suitable only for a private, temporary event test. A production version should use stricter per-room authorization and server-side validation.
